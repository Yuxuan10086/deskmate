1. 背景与目标

问题：留学生在英语授课环境中面临三重压力——听课语言障碍、随堂互动/测验容易错过、课后复习资料分散。现有翻译工具仅做单向字幕，无法主动提醒"此刻需要你做什么"，也无法在同学离开座位时兜底。

产品决策：打造桌面端"同桌"，以多模态大模型为核心，提供实时双语字幕、课堂任务主动检测与提醒、离线状态邮件兜底、课后一键归档。

可观测的完成结果：同学完成一节课后，同桌已保存课堂录音、双语文本、笔记与待办任务清单；课中出现需行动项时始终弹窗，同学不在座位时弹窗与 QQ 邮件双通道同时提醒。

设计原则

  • 简约现代：界面留白充足、单一主色、信息层级清晰，不打断听课。
  • 不打扰优先：字幕常驻、任务弹窗克制，所有提醒可一键忽略或延后。
  • 成本可控：模型组合可切换，标注每小时预估花费。

2. 术语与角色

术语定义
同学产品唯一使用者，即留学生本人。
同桌本产品。一个常驻桌面的 AI 学习助手。
课堂语言老师授课使用的语言，默认 英语。
日常语言同学母语/界面语言，默认 中文。双语字幕中译文为此语言。
网课模式音频来源为系统输出（直播/录播软件），同桌捕获系统音频。
线下课模式音频来源为笔记本麦克风，同桌录制教室现场声音。
行动项需要同学立即或课后处理的事项：随堂测验、课堂互动提问、课后作业、项目提交等。
字幕窗口实时显示双语字幕的悬浮/内嵌区域。
课程一门学期课程，含课程名、课程代码、地点、周内多段上课时间与起止周；课程下包含多次课堂记录。
课堂一次实际上课记录（原"一节课"），从"新建课堂"开始到"结束课程"归档为止，归属于某门课程。
节次/时段一天内的上课时间段（如 第1–2节 08:00–09:35），用于课程表排布与新建课堂时的自动匹配。
起止周 / 开学日期课程开设的周次范围（如 第 1–16 周）；周次依据设置中的"开学日期"（第一周周一）与系统日期计算。
课堂封面每次课堂归档后自动生成的简洁缩略图，用于课程主页与课程表的小尺寸展示。
课件（PPT）本节课使用的幻灯片文件（.pptx/.ppt/.pdf）。老师基本照 PPT 讲授，因此产品不捕获摄像头/屏幕画面，改由同学上传课件来补充板书信息。
用量明细每次模型调用的旁路计费记录：时间、所属课堂、功能环节、模型、输入/缓存/输出 Token（或 ASR 秒数）、单价与金额。所有花费汇总均由该明细按统一口径聚合。

3. 范围

P0（MVP 必备）

  • 课程管理：新建课程（课程名、课程代码、地点、周内多段时间、起止周），课程主页展示全部课堂（封面、标题、时间），课堂主页展示本次课堂记录的全部信息
  • 周课程表：按周展示、默认本周、可切换周；用颜色对比度区分本节课是否有记录，有记录可点击进入课堂主页
  • 新建课堂：根据系统时间与课程表自动预填所属课程与节次；模式选择、模型系列选择在同一界面完成
  • 课堂结束后自动生成简洁封面（适合小尺寸显示）
  • PPT 课件：课堂主页/新建课堂时可上传本节课 PPT；课程主页支持批量上传并由大模型自动归类到对应课堂；绑定后自动重新生成该课堂笔记（字幕 + 课件融合）
  • 课程开始前模式选择（网课 / 线下课）
  • 实时流式录音转写 + 翻译，双语字幕显示
  • 每 15s 用前 1 分钟字幕检测行动项，弹窗提示任务与答案
  • 摄像头每 10s 在位检测；不在位且检测到行动项时，桌面弹窗与 QQ 邮件双通道同时提醒
  • 课后自动保存：低码率录音、双语文本、笔记、待办/项目清单、课堂封面
  • 模型组合切换（含每小时成本标注）
  • 花费管理：独立界面按时间、课程/课堂、模型系列、模型、功能环节等多维度展示花费与用量，支持月度预算与超额提醒
  • 仅适配 Windows 10 / 11

P1（后续迭代）

  • 课堂记录搜索、收藏与标签
  • 行动项日历与截止提醒（系统通知）
  • 字幕导出 SRT / PDF
  • 课堂重点高亮与智能问答（基于本课字幕）
  • macOS 适配评估

明确不做

  • 不做社交/同学协作功能
  • 不做移动端；首期不做 macOS / Linux（仅 Windows 桌面）
  • 不录制/不捕获老师摄像头画面与电脑屏幕，板书信息以同学上传 PPT 替代（在位检测摄像头仅本地抓拍推理，不录像、不上传）
  • 不做实时 TTS 朗读译文（避免干扰课堂）

4. 核心流程

启动同桌→ 课程页 / 周课程表→ 新建课堂（自动预填课程与节次）→ 选模式 + 模型系列→ 开始课程→ 实时双语字幕→ 每15s行动项检测→ 弹窗/邮件提醒→ 结束课程→ 归档 + 生成封面→ 课堂主页回顾

课程 / 课堂状态机

状态触发行为
待机应用启动主导航：课程 / 课程表 / 花费 / 设置；默认进入课程页
待开始点击"新建课堂"按系统时间与课程表自动预填课程、节次、地点、周次；同学选择模式与模型系列
上课中选择模式并点击"开始课程"启动音频采集、ASR、翻译、任务检测、在位检测
暂停同学手动暂停暂停音频采集与所有模型调用；字幕窗口保留
归档中同学点击"结束课程"停止采集，生成笔记、任务清单与课堂封面，保存文件
已完成归档完成进入本次课堂主页；课程表中对应时段标记为"有记录"

5. 功能需求

5.1 课程管理（课程页） P0

目的：以"课程 → 课堂"两级结构，归档整学期的所有上课记录。

规则说明
课程页应用启动后默认进入课程页，以卡片/列表展示全部课程：课程名、课程代码、地点、本学期课堂数。
新建课程点击"新建课程"填写：课程名（必填）、课程代码（选填）、上课地点（选填）、时间（周内多段）、起止周。
周内多段时间每段含"星期几 + 开始时间 + 结束时间"，可添加/删除任意多段（如 周一 08:00–09:35、周三 10:00–11:35）；同一门课一周可排多次。
起止周填写起始周与结束周（如 第 1–16 周）；当前周次由"开学日期"（设置中配置，默认第一周周一）与系统日期计算。
课程主页点击课程进入，按时间倒序展示该课程的所有课堂；每个课堂卡片显示封面、标题（如 第 8 讲 · 10-14）、上课时间，并标注模式（网课/线下课）与"已附课件"角标。页面提供"批量上传 PPT"入口（规则见 5.8）。
课堂主页点击课堂卡片进入，展示本次课堂记录的全部信息：封面、基本信息（日期时间、节次、地点、模式、模型组合、时长、实际花费）、课件 PPT（可预览/上传/删除）、录音回放、双语文本、课堂笔记（可基于课件重新生成）、任务/项目清单。
编辑与删除课程信息可随时编辑；删除课程需二次确认，可选择同时删除其下课堂记录，或仅解除关联、保留本地文件。

结束与封面点击"结束课程"后归档并自动生成本次课堂封面（见 5.7），完成后进入课堂主页。

5.4 实时双语字幕 P0

目的：让同学听懂课堂内容。

交互演示 · FR-M2 字幕窗口
英语 → 中文 · 模型: GLM-4.5-Air
Today we'll discuss the gradient descent algorithm.
今天我们将讨论梯度下降算法。
Please complete the quiz on page 12 within five minutes.
请在五分钟内完成第 12 页的测验。
The learning rate controls how big each step is...
规则说明
音频切片按 ~5–10s 切片流式送入 ASR 模型，低延迟返回文本。
转写调用硅基流动 ASR 模型（如 XingChenASR V3.2-Ultra，免费）。
翻译转写文本流式送入对话模型翻译为日常语言，与原文逐行配对显示。
显示原文在上、译文在下；最新一行高亮并标记"直播中"。
延迟目标原文出现 ≤ 3s，译文出现 ≤ 6s。[Assumption, TBD] 取决于网络与模型响应
历史字幕历史可滚动回看；不丢失。
异常ASR 失败：重试 1 次；仍失败则该行显示"[转写失败]"并继续。翻译失败：仅显示原文。

5.5 课堂任务智能检测与提醒 P0

目的：不错过任何需要动手的课堂环节。

交互演示 · FR-M3 行动项弹窗
⚠️ 发现课堂行动项 随堂测验
老师要求 5 分钟内完成教材第 12 页的梯度下降测验。
行动指引：翻到第 12 页；第 1 题答案约为 0.01（学习率），第 2 题选 B。
规则说明
检测频率每 15s 触发一次，输入为前 1 分钟的字幕文本（含原文+译文）。
Prompt 指令要求模型判断该片段是否包含需同学行动的内容；如有，输出 JSON：{type, content, action_guide, urgency}。
行动项类型随堂测验 / 课堂互动（回答问题）/ 课堂任务 / 课后作业 / 项目提交 / 其他。
答案/指引模型基于课堂上下文给出参考答案或操作步骤；标注"答案"以便同学快速响应。
弹窗条件仅当检测到行动项时弹窗；无行动项则静默。
去重同一行动项在 2 分钟内不重复弹窗（按内容相似度判断）。
弹窗操作"知道了"（关闭）、"稍后提醒"（5 分钟后再弹）、"加入课后任务"（归档时列入清单）。
异常模型调用超时（>10s）跳过本轮；连续失败 3 次暂停检测并提示。

5.6 在位检测与邮件提醒 P0

目的：同学离开座位时，重要行动项不遗漏。

规则说明
检测方式调用笔记本摄像头，使用本地小模型（轻量人脸检测，如 MediaPipe / YOLO-nano）判断是否有人在屏幕前。
检测频率每 10s 抓拍一帧推理一次，兼顾实时性与性能/隐私压力。[Assumption, TBD] 频率可在设置中调整
隐私图像仅本地处理，不上传任何服务器；处理后立即丢弃，不存储帧。
不在位判定连续 2 次（约 20s）未检测到人脸 → 标记为"不在位"。
双通道提醒只要检测到行动项，桌面弹窗始终弹出（不因不在位而抑制）；当处于"不在位"状态时，在弹窗之外同时发送 QQ 邮件，两条通道并行触发、互为兜底，确保人离开电脑前也不遗漏。
邮件内容行动项类型、任务内容、行动指引（答案）、发生时间。
邮件服务使用 QQ 邮箱 SMTP（smtp.qq.com:465 SSL），需同学提供邮箱地址与 SMTP 授权码。
回到座位连续 2 次（约 20s）检测到人脸 → 标记"在位"，此后行动项仅弹窗、不再发送邮件；离开期间弹窗中未处理的行动项保持未读/置顶，回位后仍可看到。
异常摄像头被占用/无权限：在位检测不可用，提示同学；邮件发送失败：重试 2 次，仍失败则记录到归档日志。

样式CSS Variables + 原生 CSS（沿用 PRD 设计 Token）不引入重型 CSS 框架，保持单一主色与留白体系。
音频采集cpal（Windows 走 WASAPI）：网课模式用 loopback 捕获系统输出，线下课模式采集默认/选定麦克风WASAPI loopback 无需虚拟声卡；设备枚举与蓝牙耳机兼容在预研期验证（Q7）。
编码录音PCM 分两路：一路送 ASR；一路经内置 FFmpeg（sidecar，LGPL 动态链接）编码为 AAC 单声道 ≤32 kbps（.m4a）体积与原 PRD 估算一致（1h≈14MB）；FFmpeg 作为独立随包二进制，许可合规且便于替换。
实时传输音频分片（5–10s，WAV/Opus）→ 硅基流动 ASR；对话类走 OpenAI 兼容 SSE 流式Rust 侧用 reqwest + tokio-stream 消费 SSE，经 Tauri Event 推给字幕窗口。
摄像头 / 本地 AI取帧nokhwa 调用默认摄像头，每 10s 取 1 帧（可配置）低频取帧，CPU/隐私开销小；帧图像用完即弃、不落盘。
人脸检测ONNX Runtime（ort crate） + 轻量人脸检测模型（SCRFD-2.5G 或 YOLOv8n-face 级）纯本地推理、无联网、CPU 可跑（必要时可用核显 GPU EP）；连续 2 帧（约 20s）判定在位/不在位。
课件PPTX 解析Rust 自写解析：unzip（zip crate）+ quick-xml 提取每页标题/正文/备注.pptx 即 OOXML zip，无需安装 Office；.ppt 旧格式先引导另存为 .pptx/.pdf。
PDF 解析pdfium-render（随包 PDFium 二进制）：抽文本 + 页面光栅化缩略图课堂主页预览、批量归类的前几页摘要都从这里出。
图片型/OCR 与归类页面图像送硅基流动多模态模型 OCR；归类用一次批量对话调用输出 {课堂, 置信度, 理由}避免逐文件调用，保证一致性与成本（FR-M7）。
数据本地数据库SQLite + sqlx（离线模式、编译期校验 SQL）表：courses / sessions / materials / usage_records（用量明细）/ settings；迁移用 sqlx migrate。
文件与密钥dirs 定位 Documents；keyring crate 写 Windows 凭据管理器（DPAPI）录音/课件/封面按课程目录归档；API Key、SMTP 授权码不明文存库。
通知/邮件SMTPlettre（rustls，SMTPS 465）+ tauri-plugin-notification不在位时双通道并行：系统通知弹窗 + QQ 邮件。
封面模板渲染前端用 Canvas / SVG 模板按课程配色绘制 640×360，经 IPC 存为 cover.png（备选 Rust 侧 tiny-skia 无头渲染）零成本、即时、小尺寸文字清晰（FR-M6）。
工程化异步运行时/日志tokio；tracing + tracing-appender 按天滚动日志采集、网络、推理均异步；计费等旁路失败只记日志、不阻断上课。
测试Rust：cargo test（管线/计费/归类解析单测）；前端：Vitest + Vue Test Utils；端到端：Playwright（WebView 关键路径）计费聚合口径用单测锁定"总花费=明细求和"，防止汇总与明细不一致。
打包分发Tauri Bundler：NSIS 安装包（主） + MSI，x64/ARM64 双架构评估；代码签名证书（发布前）FFmpeg / PDFium / ONNX 模型随包或首启校验下载；WebView2 bootstrapper 内嵌。

8.3 关键运行管线

① 音频双路管线

cpal 采集 PCM→ 分片 5–10s→ ASR（硅基流动）→ SSE 翻译→ 字幕窗口（Event 推送）
同一 PCM 流→ FFmpeg AAC 32kbps→ 课堂目录 .m4a

② 行动项 + 在位 + 计费

滚动 1 分钟字幕→ 每 15s 检测调用→ 有行动项？→ 系统弹窗（始终）＋ 不在位则 QQ 邮件
每 10s 摄像头帧→ ONNX 本地推理→ 在位状态机（连续 2 帧） ｜ 每次模型调用→ 旁路异步写 usage_records→ 花费页实时聚合

8.4 外部二进制与许可

依赖用途许可/合规
FFmpeg（sidecar）AAC 录音编码LGPL 2.1+：动态链接/独立可执行、保留许可声明、提供源码获取方式；不静态链接进主程序。
PDFiumPDF 文本与缩略图BSD 3-Clause，随包包含许可声明。
ONNX Runtime本地人脸检测推理MIT；人脸检测模型需确认可再分发许可（优先选 Apache/MIT 的 SCRFD 类模型）。
WebView2 Runtime前端渲染微软随 Windows / Edge 分发，安装包内置 bootstrapper 兜底。
